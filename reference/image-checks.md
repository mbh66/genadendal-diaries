# Readings to check against the manuscript images

The translation notes flag 296 places "to be checked against the image". This list gathers them by file and by page image, so that someone with the images can work through them page by page.

- **Page (image)** is the page number in the transcription and the number of its image file: `5b (000005)` means page 5b on `NL-UtHUA_A363595_000005.jpg`. Each image holds two pages, a and b.
- **Line** is the line ID in `data/<file>.csv` where the doubtful reading stands, give or take a line. Where the note is about a lost line or a whole passage, it is the nearest line that survives.
- **Transcription has** quotes the automatic transcription, with its long s (ſ) and abbreviations.
- **Probably** is the reading or sense the note proposes. It is a suggestion; the image decides. "First copy", "second copy" and "German diary" refer to the other texts the note compares.
- **Note** links to the translation file and the note that gives the full argument.

When a reading is settled, correct the translation and its note, and delete the row here.
